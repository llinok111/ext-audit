# 局限说明

本工具只陈述**可观测事实**。以下边界是刻意设计的，不是缺陷。

## 1. 不提供安全结论

该生态不存在公开的安全审计或安全评分接口（已核实：官方仓库无相关文件，文档亦无此服务）。本工具**不做代码审计**，不下载插件包体，不静态分析 JavaScript。

因此：
- 任何插件都不会被标记为「安全」或「可信」。
- 每个插件的检查列表中常驻一条 `security-baseline`（unknown），显式声明这一能力缺失。
- 该条带 `advisory` 标记，**不参与整体状态汇总**——否则所有插件都会被永久压成 unknown，使状态字段失去区分度。

## 2. 兼容性是声明层面的比较

`version-compat` 只比较插件 `manifest.json` 中声明的 `minAppVersion` 与用户填写的 Obsidian 版本。

它**不能**证明：
- 插件在你的具体版本上实际可运行；
- 插件与你已安装的其它插件不冲突；
- 插件声明的 `minAppVersion` 是准确的。

未填写版本时，不产出此项结论，不做任何推断。

## 3. 网络失败不等于资源失效

实测（2026-10-24，500 条随机抽样）：

| 轮次 | 方式 | 结果 |
|---|---|---|
| 第一轮 | 并发 8，超时 12s | ok 243，连接失败 **257**，404 **0** |
| 第二轮 | 对失败项串行重试，超时 25s | 恢复 **225**，仍失败 32，404 **0** |

另有对照实验：同一批 12 个仓库，串行 7 条失败、并发 8 全部成功。

即：在该网络环境下，**单次探测失败完全不能作为失效证据**，甚至串行比并发更容易失败。

工具的三态处置：

| 状态 | 触发 | 是否计入失效 |
|---|---|---|
| `ok` | HTTP 200 | — |
| `missing` | HTTP 404 | 是（唯一确定性失效信号） |
| `unknown` | 超时、连接重置、5xx、429 | **否**，标记为「未确定」并要求重试 |

## 4. 许可证识别不是法律意见

识别方式为原文前 4000 字符的**文本特征匹配**：

- 只命中一组特征 → 给出 SPDX 标识，并附命中特征与原文链接。
- 命中多组冲突特征 → 标记 `ambiguous`，不做单选。
- 不匹配任何已知模板 → 标记 `none`，提示人工判定。
- 仓库无许可证文件 → `warn`（事实陈述，不是法律定性）。
- 抓取失败 → `unknown`，**不得**推断为「无许可证」。

许可证文件名不统一（实测出现 `LICENSE` / `LICENSE.txt` / `LICENSE.md` / 完全缺失），因此按候选列表逐个试探。

## 5. 数据再分发

官方 `obsidianmd/obsidian-releases` 仓库**未声明许可证**：

```
GET raw .../LICENSE      → 404
GET raw .../LICENSE.md   → 404
GET /repos/.../license   → 404 {"message":"Not Found"}
```

仓库 README 亦声明该仓库不含 Obsidian 源码、Obsidian 本身并非开源软件。

因此本工具：
- **不在交付包内附带任何数据快照**；
- 全部数据运行时从官方地址读取；
- 可选缓存由用户显式生成（`cache` 命令），存于用户指定目录，带来源 URL 与 sha256，界面与输出均显示缓存年龄；
- 每条记录保留可点击的原始来源链接。

插件自身的许可证各自独立，以各仓库 LICENSE 原文为准。

## 6. 时效性

| 时间戳 | 含义 | 更新频率 |
|---|---|---|
| 界面「拉取于」 | 本次实际抓取注册表的时刻 | 每次运行 |
| 「最近更新」 | 官方 `community-plugin-stats.json` 的 `updated` 字段 | 上游决定，**不代表当前真实状态** |
| 缓存年龄 | 本地缓存写入时刻距现在 | 用户手动刷新 |
| 页脚构建时间 | HTML 产物构建时刻 | 与数据无关 |

实测统计新鲜度（2026-10-24）：<30 天 2993 条、30–180 天 4304 条、180–365 天 611 条、>365 天 1475 条。最旧一条为 2020-11-09。

## 7. 覆盖面

- `minAppVersion` 来自各仓库当前默认分支的 `manifest.json`，反映的是**最新版本**，不是历史版本。
- `versions.json` 约半数仓库没有；缺失时低版本用户无法自动回退，此项标记为 info 而非错误。
- 未抽样到的约 8900 个插件的 manifest 可获取率未验证。
- 下载量取自官方统计文件，可能滞后。

## 8. 未验证事项

以下内容本次**未**验证，不得当作已知事实：

1. 插件运行行为与安全性。
2. `minAppVersion` 声明与实际可用性是否一致。
3. GitHub API 许可证端点在其它仓库上的行为（未认证配额 60 次/小时，未做大规模调用）。
4. 不同网络环境下连接失败率是否一致。
5. 官方下架清单之外是否还存在实际已失效但未被下架的插件。
